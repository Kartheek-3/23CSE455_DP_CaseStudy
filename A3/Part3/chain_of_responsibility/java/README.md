# Chain Of Responsibility — java

Run from this directory:

```sh
javac Sample.java TestSample.java && java TestSample ../../test-cases/chain_of_responsibility.tsv
```

Production: `Sample.java`. Tests: `TestSample.java`. Common fixture: `../../test-cases/chain_of_responsibility.tsv`.
The fixture contains 7 independent cases. Test doubles are in the test runner, outside measured production LOC.
