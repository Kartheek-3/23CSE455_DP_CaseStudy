# Cross-language Specification comparison

Java uses an interface, records, and stream predicates. Python uses structural `Protocol` typing and dataclasses. JavaScript relies on duck typing and small classes. C++ uses a virtual interface and shared pointers inside the composite so rule lifetimes are explicit. All return property id 1 for the shared composite and reject an inverted rent range. The structural roles remain Context/Client, Specification, ConcreteSpecification, and CompositeSpecification.
