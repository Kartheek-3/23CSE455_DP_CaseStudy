## 4. GRASP Information Expert collaboration

InboxReviewController

Receives the review request and delegates

InboxItem — Information Expert

Owns parsed provider name, confirmation reference, trip ID and inbox ID

Inspect Trip and existing TripItems

LINKED

Reuse item and fill missing fields

CREATED

Create one confirmed TripItem

### Role mapping in all four languages

| Role               | Java                    | Python                     | JavaScript             | C++                    |
| ------------------ | ----------------------- | -------------------------- | ---------------------- | ---------------------- |
| Information Expert | `InboxItem`             | `InboxItem`                | `InboxItem`            | `InboxItem`            |
| Expert operation   | `linkOrCreateTripItem`  | `link_or_create_trip_item` | `linkOrCreateTripItem` | `linkOrCreateTripItem` |
| Caller             | `InboxReviewController` | Same                       | Same                   | Same                   |
| Collection context | `Trip`                  | `Trip`                     | `Trip`                 | `Trip`                 |
| Domain record      | `TripItem`              | `TripItem`                 | `TripItem`             | `TripItem`             |

Why this is Information Expert: The matching and linking decision belongs to `InboxItem`, which possesses the relevant parsed booking information.

The caller delegates that responsibility. The example does not depend on Rails controller syntax, transform unrelated provider schemas or introduce a separate factory abstraction.

## 10. Preservation checks and limitations

The checksums of 112 pre-existing Part3 files were compared against the pre-implementation snapshot. Every one matched, including the frozen Strategy, Observer and Controller material.

The cumulative ZIP passed integrity checks, and generated `.class` files, C++ executables, Python caches and temporary files were excluded.

This example is deliberately in-memory and dependency-free. It does not reproduce Rails, real email parsing, Anthropic, database transactions or Expense creation. The frozen fixture set contains at most one candidate item, and matching is limited to ASCII case-insensitive comparison.

The tests establish behavior for I01–I08, not every possible malformed input or concurrent update.
