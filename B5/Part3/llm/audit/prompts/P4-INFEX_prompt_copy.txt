5. Frozen business rules.

Implement exactly:

1. Existing items may match only if they belong to the same trip.
2. Provider/item names are compared case-insensitively.
3. A matching existing TripItem is reused.
4. If its confirmation reference is missing, fill it from the incoming reference.
5. If its confirmation reference is already nonblank, preserve the existing value.
6. If its inbox link is missing, fill it with the current InboxItem ID.
7. If its inbox link already exists, preserve the existing value.
8. If there is no valid match, create a new confirmed TripItem.
9. Reject a missing or blank provider name.
10. Never attach an item belonging to a different trip.

Do not overwrite existing nonblank values.
