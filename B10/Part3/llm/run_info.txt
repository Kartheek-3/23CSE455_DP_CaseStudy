## How the tools were used
- Test runners: python tools/run_tests.py (compile + one run per language; raw output -> evidence/tests_<pattern>_<language>.txt)
- lizard: python tools/run_lizard.py (production files only -> evidence/lizard_<pattern>.txt)
- Timing: python tools/measure.py (compile outside timing, 1 warmup + 5 measured runs, time.perf_counter around subprocess.run -> evidence/timings_<pattern>.txt)
- CSV: python tools/collect_results.py (reads the evidence files -> llm/cross_language_llm_draft.csv)
- Python 3.12.7 on PATH runs the tools and the Python runners; the venv <venv> only provides lizard.
- No packages were installed for the snippets (standard library only).
