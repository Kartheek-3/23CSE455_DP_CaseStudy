   Simplify framework/database/hardware/network parts away, and list exactly what you

2. Use the SAME role/class names in all four languages (adjust only casing to each

   GoogleTest. Java test runners use a main() method; JavaScript uses CommonJS
   (module.exports / require); C++ production code is header-only (.hpp), C++14.
4. Production code and test runner must be in SEPARATE files. The production file must

   - finish with exactly one line: "<Pattern> tests: X/Y passed",
   - exit with code 0 if all passed, 1 otherwise.
