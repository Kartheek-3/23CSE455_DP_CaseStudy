# Baseline inspection scope

Inspected source root: `Part1/code/digital-wallet/src/main/java/com/b9/wallet`.

Included domains: wallet balance, fund transfer, transaction lifecycle, repository access, and notifications. Currency conversion, transaction limits, and fraud detection are deliberately excluded from the baseline because they are introduced as the three Part 2 changes. No annotation, package name, or LLM claim was counted as proof: each pattern record identifies a collaborating role and call/delegation relationship.
