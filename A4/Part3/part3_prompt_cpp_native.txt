Systems & Performance Requirements:
1. Idiomatic Modern C++ Architecture:
   - Use clean header/source separation (`.hpp` and `.cpp`) for production code.
   - Enforce RAII (Resource Acquisition Is Initialization) and safe memory management using `std::shared_ptr` and `std::make_shared`. Ensure zero memory leaks without manual `delete`.
   - Utilize standard library containers (`std::vector`, `std::map`, `std::string`) while minimizing unnecessary heap allocations and object copying (pass by const reference).
   - Leverage virtual method tables (`vtable`) for runtime polymorphism, optimized with `-O2` compiler flags under MinGW GCC 6.3.

2. Test Harness & Critical Windows Timing Fix:
   - Implement `test_runner.cpp` for each pattern, executing the exact same scenario assertions as the managed language runners (6/6 for Composite, Memento, Strategy; 5/5 for Observer, Factory, Template).
   - **Crucial Timing Constraint on Windows**: On MinGW GCC 6.3, `std::chrono::high_resolution_clock` has a known flaw where its tick resolution defaults to `GetSystemTimeAsFileTime` (~15.6 ms), truncating fast microsecond-level test executions to `0.000 ms`.
   - To capture true hardware-level execution times, use the native Windows High-Resolution Performance Counter API (`windows.h`):
     ```cpp
     LARGE_INTEGER freq, t1, t2;
     QueryPerformanceFrequency(&freq);
     QueryPerformanceCounter(&t1);
     // ... execute tests ...
     QueryPerformanceCounter(&t2);
     double elapsedMs = (t2.QuadPart - t1.QuadPart) * 1000.0 / freq.QuadPart;
     ```
   - Print output in the standard parseable format:
     `RESULT: X/X passed`
     `TIME_MS: 0.XXXX`
