| Order | Change | Commits | Extension point or implementation change | Refactoring |
|---|---|---|---|---|
| 1 | CH03 configurable filter policy | `68a60e4` (refactoring), `6f98fbf` | implementation change (launcher internals) | Extract Method `collectPostDiscoveryFilters` (preparatory) |

  - All `platform-tests`: 2452 → 2467.
  - All `jupiter-tests`: 3381 → 3388.
  - 0 failures in every run.
- `pattern_evolution.csv`: 142 rows, one per instance per version. `data/pattern_counts.csv`: counts per version, 35 → 37 instances, 10 pattern types. Both are generated by `data/build_part2_csv.py`, which reads the fork at each commit.

- `code/`: evolved source (`src/main` of the four modules), the new and changed test classes, and `demo/` (`run_ch01.sh`, `run_ch02.sh`, `run_ch03.sh`; official 6.1.3 jar vs evolved jar).
- `uml/`: redrawn diagrams for the changed and new instances.
