# Strategy – Workout recommendation strategy (JAVASCRIPT)

## Purpose
Strategy – Workout recommendation strategy demonstrates the assigned design pattern using a small standalone example.

## Files
- `WorkoutStrategy.js`: pattern implementation and/or executable example.
- `WorkoutStrategy.test.js`: test runner.

## Run
```bash
node WorkoutStrategy.test.js
```

Run the command from this folder. For C++ on Windows PowerShell, execute the generated `.exe` file after compiling.

## Scope note
This is an educational, standalone implementation. It illustrates the pattern and is not wired into the original Gym Management System. The FastAPI and Angular dependency-injection examples are represented by language-neutral constructor/provider injection equivalents in Java, C++, and JavaScript; they do not require those frameworks.
