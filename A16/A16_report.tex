\begin{abstract}
This report studies the design patterns present in the \emph{Hospital Management System}, a Spring Boot microservices backend with a PostgreSQL database. Part 1 reports a baseline candidate set of four confirmed pattern categories comprising four recorded instances: the Builder pattern (GoF, creational; 1 instance), Singleton (Spring Idiom; 1 instance), Proxy (GoF, structural; 1 instance), and the architectural pattern Repository (1 instance).
\end{abstract}
