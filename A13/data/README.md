# Canonical datasets and source snapshots

Consolidated copies of the dataset CSVs named in the report template. The per-part files named in the assignment tree are in `Part1/`, `Part2/` and `Part3/llm/`.

- `patterns.csv`: confirmed pattern instances for a source version.
- `pattern_counts.csv`: counts derived from verified pattern records.
- `patterns_evolution.csv`: pattern instance status across baseline and changes.
- `cross_language.csv`: Part 3 cross-language measurements (one row per pattern and language).
- `llm.csv`: record of LLM use and verification for all parts.

Headers follow the assignment specification; paths are relative to the team folder. Source snapshots are referenced by commit in the root `README.md` and `Part2/code/README.md`.
