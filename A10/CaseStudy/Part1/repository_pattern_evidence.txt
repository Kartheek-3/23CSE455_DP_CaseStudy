Pattern interpretation:
Across the inspected modules, API endpoints depend on repository objects rather than directly implementing the corresponding database operations. The repositories encapsulate database access through the Database abstraction. This provides source evidence for the Repository Pattern.

Scope limitation:
Only patterns supported by source-code evidence are recorded as confirmed patterns. Other possible architectural mechanisms are documented separately and are not counted as formal pattern instances without sufficient implementation evidence.
